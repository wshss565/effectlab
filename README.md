## 它做什么

对标 effect.app 的浏览器端实时特效工具：上传图片 → 叠加特效 → 实时预览 → 原尺寸导出。同时它是一个个人作品展示站（展示页 + 编辑器双视图，hash 路由）。

**12 种实时特效**：双色调、单色、阈值、调色、录像带、故障、动态模糊、位移、条纹、热成像、有损故障、复古终端。

**编辑器能力**：

- 效果链叠加：多个特效串联应用，叠加顺序即栈序，可随时开关任何一个
- 对比滑块：拖动分割线，原图 / 效果后画面实时对照
- 预设系统：效果组合存为预设，支持 JSON 导入导出
- 一键导出：原尺寸或 2x / 4x 放大导出 PNG，导出与预览同一渲染管线

**设计原则**：离线优先（断网也能工作，全部处理在本地）、少即是多（砍掉菜单噪音，只保留塑造画面效果的核心控制）、持续小步迭代。

## 技术栈

原生 ES Modules，无框架 ｜ esbuild 打包为单文件（CSS/JS/woff2 全部内联）｜ WebGL fragment shader 效果链，失败自动降级 Canvas 2D ｜ hash 路由双视图

## 本地运行

双击 `index.html` 即可（`file://` 无降级项）。

```bash
# 重新构建
bash build.sh        # 需要 tools/bin/esbuild.exe 或系统 esbuild
```

## 目录

```
.
├── index.html          # 构建产物（单文件应用，开箱即用）
├── src/
│   ├── main.js         #   入口 / hash 路由
│   ├── editor/         #   编辑器：效果链、渲染管线、预设、导出
│   ├── components/     #   页面框架组件
│   └── styles/         #   样式（含内联 woff2 字体）
├── assemble.mjs        # 单文件装配（模板替换）
└── build.sh            # esbuild 打包 + 装配
```
